\# SOC Homelab



Laboratorio personal de ciberseguridad orientado al área de Blue Team y operaciones de un Centro de Operaciones de Seguridad (SOC).



Este proyecto reúne diferentes laboratorios prácticos realizados en un entorno controlado, con el objetivo de desarrollar y documentar conocimientos relacionados con detección de amenazas, análisis de eventos, seguridad de redes e investigación de incidentes.



\## Laboratorios



\### LAB001 - Introducción a Sysmon



Instalación y configuración de Sysmon en Windows para la generación y análisis de eventos de seguridad.



\### LAB002 - Nmap vs Firewall



Análisis del comportamiento de un firewall frente a diferentes técnicas de reconocimiento y escaneo de red utilizando Nmap.



\### LAB003 - Wireshark



Captura y análisis de tráfico de red utilizando Wireshark para identificar protocolos, comunicaciones y posibles comportamientos sospechosos.



\### LAB004 - Investigación de alertas de seguridad



Simulación de una investigación realizada por un analista SOC a partir de una alerta de seguridad, siguiendo un proceso de análisis y determinación del incidente.



\## Herramientas utilizadas



\- Windows 11

\- Kali Linux

\- Sysmon

\- Nmap

\- Wireshark

\- VirtualBox

\- Análisis de eventos

\- Análisis de tráfico de red

\- Técnicas de Blue Team

\- Investigación de incidentes



\## Objetivo



Desarrollar experiencia práctica en operaciones de seguridad, detección de amenazas, análisis de eventos e investigación de incidentes mediante laboratorios realizados en un entorno controlado.



Este repositorio se encuentra en desarrollo y será actualizado progresivamente con nuevos laboratorios, investigaciones y proyectos relacionados con ciberseguridad.
