
# LAB004 — Investigación de Alertas SOC y SIEM

## Descripción

Este laboratorio está orientado a la **monitorización, análisis e investigación de alertas de seguridad dentro de un entorno SOC (Security Operations Center)**.

El objetivo es pr
acticar el proceso que seguiría un **Analista SOC L1** al recibir una alerta de seguridad: realizar el triage inicial, analizar los eventos y registros relacionados, investigar indicadores, correlacionar información, determinar la naturaleza de la alerta y documentar los resultados.

Las investigaciones documentadas en este laboratorio se realizan mediante **LetsDefend**, utilizando escenarios y alertas simuladas de un entorno SOC de entrenamiento.

---

##  Objetivos

Los principales objetivos de este laboratorio son desarrollar y demostrar conocimientos prácticos en:

- Monitorización de alertas de seguridad.
- Triage inicial de alertas.
- Análisis de eventos y registros.
- Investigación dentro de un SIEM.
- Correlación de eventos.
- Identificación de Indicadores de Compromiso (IOC).
- Investigación de direcciones IP.
- Investigación de dominios y URLs.
- Análisis de hashes.
- Identificación de usuarios y equipos afectados.
- Detección de actividad sospechosa.
- Clasificación de alertas.
- Documentación de investigaciones.
- Determinación de posibles acciones de respuesta o escalamiento.


##  Habilidades demostradas

Este laboratorio busca demostrar conocimientos prácticos relacionados con el trabajo de un **Analista SOC L1**, principalmente:

**Monitorización → Triage → Investigación → Correlación → Clasificación → Documentación → Escalamiento**

Entre las habilidades practicadas se encuentran:

* Interpretación de alertas.
* Análisis de eventos relacionados.
* Búsqueda de evidencia dentro del SIEM.
* Identificación de actividad potencialmente maliciosa.
* Análisis de IOC.
* Correlación de diferentes eventos.
* Diferenciación entre actividad legítima y sospechosa.
* Documentación clara de los hallazgos.
* Determinación de cuándo una alerta requiere escalamiento.
