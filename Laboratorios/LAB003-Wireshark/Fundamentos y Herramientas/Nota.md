# Fundamentos y Herramientas

Esta sección contiene una recopilación de funcionalidades y herramientas de **Wireshark** utilizadas para la captura, navegación, filtrado y análisis de tráfico de red.

El objetivo es documentar de forma práctica el manejo de las principales funciones de la herramienta y mostrar, mediante evidencias, cómo pueden utilizarse durante un análisis de tráfico.

## Objetivos

- Familiarizarme con la interfaz de Wireshark.
- Conocer las principales herramientas de análisis.
- Aprender a navegar entre paquetes.
- Aplicar filtros para localizar información específica.
- Identificar diferentes protocolos.
- Utilizar las funciones de búsqueda dentro de una captura.
- Obtener información de los archivos de captura.

## Contenido

### Captura de tráfico

Documentación de las funciones relacionadas con la captura de tráfico:

- Inicio de una captura.
- Detención de una captura.
- Reinicio de una captura.
- Visualización del tráfico capturado.

### Filtrado y visualización

Uso de diferentes mecanismos para facilitar el análisis del tráfico:

- Filtros de visualización.
- Filtrado por protocolos.
- Colores para identificar diferentes tipos de tráfico.
- Selección de paquetes.

### Navegación y búsqueda

Herramientas utilizadas para localizar paquetes específicos dentro de una captura:

- `Go to Packet`
- `Find Packet`
- Búsqueda de información dentro de los paquetes.
- Navegación entre paquetes.

### Gestión y análisis de capturas

Funciones relacionadas con los archivos y las capturas de tráfico:

- Visualización de las propiedades del archivo.
- Obtención del valor hash de una captura.
- Fusión de capturas.
- Análisis individual de paquetes.

### Documentación de paquetes

Funciones utilizadas para agregar información durante el análisis:

- Agregado de comentarios a paquetes.
- Identificación de paquetes relevantes.
- Registro de evidencias durante una investigación.

## Evidencias

Cada funcionalidad documentada incluye capturas de pantalla que muestran su utilización directamente en Wireshark.
